## Mobile & Tablet POS

## Open-Source POS

- [ERPNext](https://erpnext.com/) - ERPNext is an open-source ERP suite with a POS module for retail businesses. It can be self-hosted under the GPL or used via Frappe Cloud with a subscription. ([Read more](/details/erpnext.md)) `Open Source` `Self-Hosted` `API` `ERP` `Retail`
- [Floreant POS](https://floreantpos.org/) - Floreant POS is an open-source restaurant point-of-sale application for Windows and Linux. It is self-hosted, free to use, and licensed under the GPL. ([Read more](/details/floreant-pos.md)) `Open Source` `Self-Hosted` `GPL` `Restaurant`
- [Odoo Point of Sale](https://www.odoo.com/) - Odoo Point of Sale is a POS module within the Odoo ERP suite for retail and restaurant use. The community edition is open source and self-hosted; Odoo Online is a paid cloud service. ([Read more](/details/odoo-point-of-sale.md)) `Open Source` `Self-Hosted` `API` `ERP`

## Payment-Integrated POS

- [Square](https://squareup.com/) - Square is a point-of-sale and payment processing platform for small and midsize businesses. The POS app is free; users pay per-transaction processing fees and optional hardware or software upgrade costs. ([Read more](/details/square.md)) `Freemium` `Payment-Integrated` `API` `Small Business`
- [SumUp](https://sumup.com/) - SumUp is a mobile payment and point-of-sale solution for small businesses. The app is free; costs come from card readers and transaction processing fees. ([Read more](/details/sumup.md)) `Freemium` `Payment-Integrated` `Mobile` `API`
- [Zettle](https://www.zettle.com/) - Zettle by PayPal is a mobile POS and card reader solution for small sellers. The app is free, with revenue from hardware sales and transaction fees. ([Read more](/details/zettle.md)) `Freemium` `Payment-Integrated` `Mobile` `PayPal`

## Restaurant POS

- [NCR Aloha](https://www.ncrvoyix.com/) - NCR Aloha is a restaurant POS platform from NCR Voyix for enterprise hospitality. It supports cloud and on-premise deployment with paid licensing and API access. ([Read more](/details/ncr-aloha.md)) `Enterprise` `Paid` `API` `On-Premise` `Cloud`
- [Revel Systems](https://www.revelsystems.com/) - Revel Systems is a cloud-based POS for restaurants and retail. It provides enterprise-grade features such as inventory, employee management, and API integrations under a paid subscription. ([Read more](/details/revel-systems.md)) `Paid` `API` `Enterprise` `Restaurant Management`
- [SambaPOS](https://sambapos.com/) - SambaPOS is a Windows-based point-of-sale system for restaurants and hospitality. It provides a free edition with optional paid licenses for advanced modules and API access. ([Read more](/details/sambapos.md)) `Freemium` `Free Plan` `Windows` `API`
- [Toast](https://toasttab.com/) - Toast is a restaurant POS platform built for foodservice operations. It includes front-of-house, kitchen display, and management tools under a paid subscription model. ([Read more](/details/toast.md)) `Paid` `API` `Restaurant Management` `Kitchen Display`
- [TouchBistro](https://touchbistro.com/) - TouchBistro is an iPad-based restaurant POS system for foodservice businesses. It offers tableside ordering, menu management, and payments through a paid subscription. ([Read more](/details/touchbistro.md)) `Paid` `API` `iPad` `Restaurant Management`

## Retail POS

- [KORONA POS](https://www.koronapos.com/) - KORONA POS is a cloud-based retail point-of-sale system for small and midsize merchants. It includes inventory, reporting, and API integrations with a paid subscription model. ([Read more](/details/korona-pos.md)) `Paid` `API` `Cloud` `Retail`
- [Lightspeed](https://www.lightspeedhq.com/) - Lightspeed Retail is a cloud-based POS and inventory platform for retail businesses. It serves small to enterprise merchants with paid subscriptions and API access for integrations. ([Read more](/details/lightspeed.md)) `Paid` `API` `Enterprise` `Inventory` `E-commerce`
- [Shopify POS](https://www.shopify.com/pos) - Shopify POS is a retail point-of-sale system that integrates with Shopify e-commerce. It is for merchants using Shopify plans and requires a paid subscription; hardware and payment processing are extra. ([Read more](/details/shopify-pos.md)) `Paid` `API` `E-commerce` `Inventory`
